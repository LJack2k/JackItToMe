# JackItToMe 1.0.0

First stable release. The feature set has settled and the mod does what it set
out to do, so it leaves 0.x behind.

## The recipe button

The button that pulls every ingredient for a recipe now works the same whether
you use JEI, EMI or REI.

- **It shows up on EMI.** EMI hides mod-added recipe widgets behind a setting
  that is off by default, which left the button invisible for most EMI players.
  It no longer depends on that setting.
- **It no longer covers the recipe.** On EMI and REI the button sits in a strip
  beside the recipe rather than inside it. Short recipes such as anvil, fuel and
  AE2's P2P attunement used to have the button land on top of their contents.
- **Its tooltip opens beside the button** on EMI and REI, instead of over the
  recipe, so the red and green markers showing which ingredients are missing
  stay visible while you read it.
- **It is hidden when there is nothing to pull** - when you open a recipe with
  only your own inventory behind it.
- New hand-drawn icon, with a hover state.

## Configuration

A client config, under Mods -> JackItToMe -> Config:

- `showRecipeButton` - whether the recipe button is shown. The G keybinds are
  unaffected and keep working with it off.
- `buttonOffsetX` / `buttonOffsetY` - move the button from its default spot.
  EMI and REI only; JEI decides where its own recipe buttons go.
- `placementKeys` - opt in to moving the button in-game with Ctrl and the arrow
  keys, Ctrl+Home to reset. Each nudge is saved, so you can turn it back off
  once the button sits where you want it. EMI and REI only.
