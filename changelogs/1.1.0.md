# JackItToMe 1.1.0

A security fix. Update if you run this mod on a server.

## Fixed

- **Duplication through crafting result slots.** Hovering the result slot of a
  crafting table and pressing the pull key handed you the result without using
  up the ingredients in the grid. The same applied to every output slot that
  only previews a result: the 2x2 inventory grid, anvil, smithing table,
  stonecutter, loom, grindstone, cartography table and villager trades. These
  slots are no longer treated as a source, so the pull key and the recipe
  button leave them alone. Chests, furnaces and the other storage you pull from
  are unaffected.
